首发执行方向：本地单用户、多工作区、受限多任务；Electron 薄宿主和独立 runtime；核心不依赖 Electron；同一 AppClient 经 IPC 和受控 loopback HTTP 工作。真实模型优先官方 OpenAI 的公开接口/API key 路径，不读取 ambient auth，不承诺任意兼容服务。文件编辑使用 CodeMirror 方向；预览只读；扩展选择明确受控的首发扩展面，不以任意 Node 代码或 UI 代码加载冒充安全插件生态。具体协议、扩展格式与版本由对应实现决策记录确定。

3. **恢复与长期资源**：[离线维护 CLI](STORE-MAINTENANCE.md)已形成备份、隔离恢复与只读检查闭环；继续验证安装包内维护工具、三平台文件系统和更长负载。[最新小规模基准](benchmarks/capacity-full-2026-10-19.md)仅覆盖 10/1,000 个空历史会话，不代表长消息/工具审计/并发或物理 SSD 性能。
4. **原生与浏览器验收**：验证 preload、utility、渲染、目录选择、密钥链、IME、滚动和视觉。macOS 双架构和 Ubuntu 22 已有真实启动/流式证据，但完整 GUI 失败；优先复验弹窗 bounds、Close 实际点击及焦点，继续诊断 Windows 与 Ubuntu 24。不能把静态类型、SSR 或 Node-mode 验证当图形通过。
5. **交付门禁**：逐平台完成安装、适用签名/公证、更新与回退、辅助技术和关键任务闭环。真实服务只在有具体授权时使用，默认验收继续使用确定性 provider。

普通技术取舍由负责人直接决定并留下理由、限制与测试；不能因等待非必要产品确认而闲置可执行工作。涉及安全确认或确实缺少设备/凭据时，报告具体阻断，同时继续不依赖它的实现。
